The invariant "clear error when task transitions into Running state" is currently only enforced in RoleSession::set_state in zbobr-dispatcher/src/task.rs. It should be in the default TaskMut::set_state impl in zbobr-api/src/backend.rs so all backend implementations get it for free. The dispatcher's set_state already overrides this (with additional confirm logic), so it should also keep its own clear logic.
