In zbobr-dispatcher/src/cli.rs, restructure the run() function to wrap provider selection + MCP server + executor execution in a loop. On connectivity_failure (connectivity/quota), exclude the provider, abort the server, and retry with the next available provider. The loop terminates when: execution succeeds, a non-connectivity failure occurs, execution is interrupted, or select_provider() returns an error (all providers exhausted). The once-per-stage setup (worktree, branch, stage counter, prompt text, etc.) stays outside the loop. Each attempt pushes its own StageContext entry and stores output/prompt. Only the final (non-retried) attempt calls finalize_stage_session().
