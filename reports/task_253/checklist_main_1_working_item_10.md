In ZbobrRepoBackendGithub::from_config() (github.rs), after calling validate(), parse the repository string using parse_github_repo() and store the normalized full_name back into backend_config.repository. This ensures all downstream uses (validate_connectivity, ensure_pr_url, find_existing_pr, update_pr_body, update_worktree) work correctly even when repository is set to a full HTTPS URL or SSH URL in the config.
