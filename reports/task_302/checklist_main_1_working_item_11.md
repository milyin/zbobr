In WorkflowToml::resolve_paths, role/stage prompt paths should be resolved against the effective prompt base: the resolved prompts_dir when present, otherwise config_dir. Currently they're all resolved against config_dir, which breaks when prompts_dir is set (e.g., prompts_dir="prompts" + role prompt "planner.md" should yield /config/prompts/planner.md, not /config/planner.md). Update the method and the tests that assert the wrong behavior.
